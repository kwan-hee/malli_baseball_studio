# 강의 CH1-3 「그림체 기준 정하기」 콘티 v2 (대본 단일 출처)

- 진행: 릴리 선생(강사, Leda) + 말리(Kore). 대상 = 수강생(어른). 말투 = 친절한 해요체. 말리 = 다섯 살 아이 말투.
- 근거·기준 = `그림체_기준안.md`, 계획 = `계획서_v2.md` (2026-10-29 승인). 티키타카: 말리의 무서운 호랑이 / 심사위원 말리 O·X / 탐정 말리 / 진짜 말리 찾기.
- 시간은 예상치. 실제 길이는 TTS 녹음에 맞춤. 목표 약 8분.
- 필드: 화자 / 대사(낭독) / 화면 / 클립(Cxx (시작 그림) 동작 — 점수판은 make_clip_inputs.py) / 소리. 대사 외에는 낭독하지 않음.

- 씬 첫 문장은 감탄사·의성어로 시작하지 않음 (whisper 경계 교훈).
