# 강의 CH3-1 「퍼블릭 도메인 동화 150편」 — 1차 게이트 개요 (2026-10-30)

> **이 파일은 맥미니 Orca 의 Claude 에게 그대로 넘겨 강의 영상을 만들게 하는 입력 문서다.**
> 맨 아래 「Orca 실행 순서」를 따른다. 강의 내용(무엇을 가르치는지)은 이 개요가 기준이고, 대본·콘티는 승인 후에 쓴다.

- 커리큘럼 위치: CHAPTER 3 「어떤 동화를 만들까요? 소재 고르기」 · 1번 강의 (커리큘럼 html 권장 10:00, "저작권 걱정 없는 동화: 퍼블릭 도메인 동화 150편 목록 — 이솝 우화, 그림 형제, 안데르센, 한국 전래동화")
  - CH3 구성: **3-1 퍼블릭 도메인 동화 150편(이번)** → 3-2 적합도 상·중·하 나누기(08:00) → 3-3 후보 4개 받고 고르기(06:00, 실습)
- 등장: 릴리 선생(강사, Leda) + 말리(Kore, 강아지 보조 — 기준 시트 그대로, 안경·지시봉 등 선생님 소품 금지). CH2 강의와 같은 교실·연출(이름표, 카드 장면 작은 화면, "잠깐 멈추고 따라 해 보세요").
- 앞 강의와 이어짐: CH2-5 「프로젝트 폴더 구조 만들기」에서 만든 작업실 폴더에 오늘 **동화 목록 파일**을 하나 추가한다.
- 목표: 수강생이 ①퍼블릭 도메인이 무엇이고 어떤 동화가 "저작권 걱정 없는" 동화인지 한 문장으로 말하고 ②Claude 에게 150편 목록을 표로 받아 내 작업실에 저장하고 ③이 목록을 쓰는 두 가지 방법(그대로 영상 동화 / 바탕으로 새 동화) 중 하나를 고를 수 있게 한다.

## 150편 수집 방법 (강의 ③ 파트의 내용)

1. **어디서 모으나 — 다섯 갈래 + 세계 민담**: 이솝 · 그림 형제 · 안데르센 · 페로 · 한국 전래동화, 그리고 일본·중국·인도·아랍·러시아·아프리카 민담. 갈래마다 "대표작 + 아이들에게 덜 알려진 짧은 이야기"를 섞는다.
2. **누가 모으나 — Claude 에게 시킨다**: 수강생은 아래 실습 프롬프트를 붙여 넣기만 한다. 한 번에 150편을 받지 말고 **갈래별로 나눠** 받는다(긴 표는 중간에 끊기거나 같은 편이 겹치기 쉬움).
3. **AI 가 지어낸 동화 걸러내기**: Claude 가 없는 이야기를 그럴듯하게 만들어 넣을 수 있다 → 낯선 제목은 원문 출처에서 실제로 있는지 확인한다.
   - 세계 동화 원문: Project Gutenberg (gutenberg.org, 영어 원문 무료 공개)
   - 한국 저작권 만료 자료: 공유마당 (gongu.copyright.or.kr, 한국저작권위원회)
   - 한국 옛이야기: 한국구비문학대계 (gubi.aks.ac.kr, 한국학중앙연구원)
   - 강의에서는 사이트를 깊이 다루지 않고, 실제 캡처 1장씩 + "모르는 제목만 검색" 원칙만 보여 준다.
4. **목록 형식 — 표 한 장, 열 다섯 개**: 말리 채널 `docs/10_TALE_LIBRARY.md` 와 같은 모양.

   ```markdown
   ## 이솝 우화 (그리스)

   | 제목 | 줄거리 | 교훈 | 적합도 | 비고 |
   |------|--------|------|:---:|------|
   | 개미와 비둘기 | 서로를 구해 주는 개미와 비둘기 | 은혜는 돌아온다 |  |  |
   ```
   - 줄거리는 **한 줄**, 교훈은 **한 가지**(한 편에 교훈 하나 — 09_STORYBOOK 규칙).
   - **적합도·비고 칸은 오늘 비워 둔다** → 3-2 에서 채운다(상·중·하, 순화 포인트, 이미 만든 편 ✅).
   - 파일 이름·위치: 작업실 폴더의 `동화_라이브러리.md` (확인 질문 3).

**수강생 실습 프롬프트 (화면에 그대로 보여 주는 문구, 초안)**

```text
저작권이 끝난 퍼블릭 도메인 동화 목록을 만들어 줘.
이번에는 "이솝 우화"만 30편.
규칙:
1. 작가가 세상을 떠난 지 100년이 넘은 원작, 또는 작자 미상 옛이야기만.
2. 영화나 요즘 동화책에서 새로 붙인 이름·설정은 빼고, 원작 줄거리로만 적어.
3. 표 하나로: 제목 | 줄거리(한 줄) | 교훈(한 가지) | 적합도(비워 둬) | 비고(비워 둬)
4. 확실하지 않은 제목은 넣지 말고, 맨 아래에 따로 적어 줘.
다 만들면 동화_라이브러리.md 파일에 "## 이솝 우화" 제목으로 저장해 줘.
```
- 같은 프롬프트에서 갈래 이름과 편수만 바꿔 여섯 번 실행 → 약 150편. (이솝 30 · 그림 25 · 안데르센 20 · 페로 5 · 한국 전래 40 · 세계 민담 30)
- "100년"으로 쓴 이유: 70년 기준보다 넉넉하게 잡아 나라마다 다른 기준까지 피하기 위해서다.

## 150편을 쓰는 두 가지 방법 (강의 ④·⑤ 파트의 내용)

| | A. 그대로 영상 동화로 | B. 바탕으로 나만의 새 동화 |
|---|---|---|
| 하는 일 | 150편 중 한 편을 골라 **원작 줄거리 그대로** 말리가 들려주는 영상으로 | 한 편의 **뼈대(교훈·사건 순서)만 빌리고** 주인공·장소·결말을 바꿔 새 이야기로 |
| 바꾸는 것 | 말리 등장 + 5~7세 눈높이 말투 + 순화(무서운 장면 → 3-2 기준) | 주인공(우리 아이·반려동물·말리 친구) · 장소(우리 동네·집) · 결말(말리 규칙: 밝게, 교훈 한 줄) |
| 장점 | 아이들이 아는 제목이라 검색·클릭이 잘 됨. 줄거리 검증이 쉬움 | 세상에 하나뿐인 이야기 → 다른 채널과 겹치지 않음. 우리 가족 맞춤 |
| 주의 | 같은 제목 영상이 많다 → 말리만의 결말·말투로 차이를 만든다 | 원작과 너무 멀어지면 교훈이 흐려진다 → "교훈은 그대로" 하나만 지킨다 |
| 말리 채널 실제 사례 | 「말리와 욕심쟁이 개」(이솝, 순화 필요 없음) · 「말리와 북풍과 해님」(원작 무해, 북풍을 웃긴 구름 얼굴로) | 「하린이와 초코의 이상한 나라」 강의 샘플(『이상한 나라의 앨리스』 뼈대 → 우리 아이 하린과 반려견 초코가 주인공) |

- B 의 "세 가지만 바꾸기" 카드: ①주인공 바꾸기 ②장소 바꾸기 ③결말을 밝게 → 예시 1개를 화면에서 실제로 Claude 에게 시켜 결과 3줄을 보여 준다(예: 「개미와 비둘기」 → "말리와 공원의 개미" — 말리가 물웅덩이에 빠진 개미를 나뭇잎으로 구하고, 나중에 개미들이 말리가 잃어버린 공을 찾아 줌). 화면 결과는 대본 단계에서 실제 Claude 출력으로 확정한다.
- 어느 쪽이든 다음 단계는 같다: 3-2 적합도 → 3-3 후보 4개 → CH4 개요 확인.
