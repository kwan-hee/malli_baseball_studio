## 화면 이미지 제작 방법 (제안)

"실제 화면처럼, 한 번만 봐도 따라 할 수 있게"를 위해 화면 종류마다 방법을 나눕니다.

| 화면 종류 | 방법 | 이유 |
|---|---|---|
| 웹 페이지 (공식 설치 페이지, 다운로드 페이지) | **크롬 자동화로 실제 캡처** | 진짜 화면이라 수강생이 본 화면과 100% 같음. 무료 |
| 터미널·PowerShell 화면 | **HTML로 똑같이 그려서 PNG 렌더링** (실제 출력 글자 그대로) | AI 이미지 생성은 화면 속 글자를 자주 틀리게 그림 → 명령어 한 글자만 틀려도 따라 하다 실패. HTML은 글자가 정확하고 무료 |
| 로그인·승인 브라우저 화면 | 실제 캡처 후 **이메일·계정 정보 가림** | 개인정보 노출 방지 |
| Windows 시작 메뉴·설정 화면 | 이 PC에서 실제 캡처 (가능하면) / 안 되면 HTML 재현 | 진짜 화면 우선 |
| 릴리·말리 동작 장면, 비유 그림 | Gemini 이미지 (기존 시트·참조 첨부) | 캐릭터 일관성은 기존 규칙대로 |

- 모든 화면 캡처에는 **번호 동그라미 ①②③ + 빨간 테두리 + 확대 박스**를 덧입혀서 "어디를 누르는지"를 바로 보이게 합니다.
- 화면 장면에는 릴리 원형 작은 화면(PIP)을 띄워 CH1과 같은 진행감을 유지합니다.

## 비용 예상 (2차 게이트에서 확정)

- 화면 이미지 약 15~18장: 캡처·HTML 렌더링이라 **무료**
- 새 캐릭터 그림 약 5~6장(Gemini): 릴리가 노트북 앞에서 설명, 말리가 검은 창에 놀람, 말리 오류에 당황, 브라우저 승인 축하 등
- 클립: 강의 점수판 규칙(캐릭터 장면 motion≥4 & importance≥65). 화면 장면이 많아 CH1보다 적을 것으로 예상(약 8~12개, CH1 클립 재사용 우선). 테스트 = Wan 3.0 · 480p · 소리 켬 → 확인 후 정식
- TTS·카드·조립은 무료/승인 불필요

## 확인이 필요한 점

1. **운영체제 비중**: Windows 중심 + Mac 요약 1분(제안) / Windows·Mac 똑같이 / Windows만
2. **화면 이미지 방법**: 위 표처럼 실제 캡처 + HTML 재현 중심(제안) / 요청하신 대로 Gemini로 생성 중심
3. **설치 방법 하나만 보여 줄지**: 공식 권장 한 줄 설치만(제안) / 데스크톱 앱도 짧게 소개
4. 로그인 장면을 **이 PC에서 실제로 다시 진행**해 캡처해도 되는지 (로그아웃 → 재로그인 필요. 계정 정보는 가림)
5. 요금제 안내 수위: "Pro 이상 필요"까지만 말할지, 월 요금 금액까지 말할지 (금액은 바뀔 수 있어 제안은 금액 생략)
