# 강의 CH2-1 「Claude Code 설치와 로그인」 콘티 (대본 단일 출처)

- 진행: 릴리 선생(강사, Leda) + 말리(강아지 보조, Kore). 대상 = 수강생(어른, 컴퓨터 초보). 말투 = 친절한 해요체.
- 시간은 예상치(초당 약 4.5자, 1-2 실측 비율). 실제 길이는 TTS 녹음에 맞춤. 목표 약 10분.
- 필드: 화자 / 대사(낭독) / 화면 / 클립 / 소리. 대사 외에는 낭독하지 않음.
- 1차 게이트 확정(2026-10-29, 제안대로): Windows 중심 + Mac 요약 1분 / 화면 = 실제 캡처 + 터미널 HTML 재현, Gemini는 캐릭터 장면만 / 공식 한 줄 설치만(데스크톱 앱 소개 안 함) / 로그인 장면은 이 PC에서 재로그인해 캡처, 계정 정보 가림 / 요금 금액 생략("Pro 이상").
- 화면 코드: W = 웹·Windows 실제 캡처, T = 터미널 HTML 재현, K = 설명 카드, P = 새 캐릭터 그림, I·M·J = 1-2 그림 재사용.
- 터미널 재현 규칙: 사용자 이름은 `malli`(실제 PC 이름 노출 금지), 글꼴 Cascadia Mono / D2Coding, 실제 출력 문구를 한 글자도 바꾸지 않음. ※ T07~T11(Claude Code 첫 실행 화면) 문구는 캡처 단계에서 실제 화면을 보고 확정하고, 대사가 화면과 다르면 TTS 전에 대사를 고침.
- 모든 캡처·재현 화면에 ①②③ 번호 동그라미 + 빨간 테두리 + 확대 박스 + 릴리 작은 화면(C12).
- 따라 하기 멈춤: 수강생이 직접 입력하는 화면(T02·T05·T06·T07·T08·T11)은 대사가 끝난 뒤 화면을 3초 더 유지하고 구석에 "⏸ 멈추고 따라 해 보세요" 표시. 이 시간은 compose 에서 장면 끝에 무음으로 붙임(약 +18초).
- 장면 시간은 예상치. TTS 후 실측으로 다시 매김.
