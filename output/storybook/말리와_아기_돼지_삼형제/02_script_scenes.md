# 말리와 아기 돼지 삼형제 — 대본·장면 설계

원작: 영국 민담 "아기 돼지 삼형제" (TALE_LIBRARY "상")
교훈: 성실하게 준비하기 — 조금 힘들어도 차근차근 튼튼하게 준비하면 무서운 일이 와도 끄떡없다.
톤: 늑대는 "우습고 어수룩한" 심술쟁이. 잡아먹기·굴뚝 결말 없음(순화). 밝은 결말.

## 개요 (3줄)

1. 아기 돼지 삼형제가 각자 집을 짓는다 — 첫째 지푸라기, 둘째 나무, 막내 벽돌.
2. 커다란 늑대가 후후~ 불어 지푸라기집·나무집을 날려 버리지만 형들은 무사히 막내네로 대피.
3. 벽돌집은 꿈쩍없고, 늑대는 불다 지쳐 도망. 형들도 벽돌로 다시 짓기로 하며 화해·감사.

## 순화 포인트

- 잡아먹기 위협 → "집 뺏으려는 심술쟁이 늑대" + 문 열어라/안 돼요 후렴.
- 굴뚝·냄비 결말 삭제 → 늑대가 불다 지쳐 데굴데굴 구르고 도망.
- 형들 위험 → 무너지기 전에 후다닥 대피, 아무도 다치지 않음.
- 반복 후렴: "아기 돼지야, 문 열어라!" / "안 돼요, 안 돼요, 절대 안 돼요!" (아이들이 따라 말하는 구조)

## 말리 등장 규칙

- 말리 = 진행자/관찰자. s01·s05·s10 만 등장. 내부 이야기 씬(s02~s04, s06~s09)은 NO_MALLI.
