# 야구사전 28편 "타점(RBI)" — 리서치 노트 (웹 교차검증)

## 정의
- **타점(RBI, Run Batted In) = 타자가 타격으로 주자(또는 자신)를 홈으로 불러들여 만든 득점.**
- 홈런은 자신이 홈에 들어온 것도 타점 → 만루 홈런 = 4타점.

## 타점이 인정되는 경우
- 안타로 주자 홈인 / 홈런 / **희생플라이·희생번트로 득점** / **만루 밀어내기 볼넷·사구** / 병살 아닌 내야땅볼로 득점.
- 즉, 타자가 아웃되면서 낸 점수(희생)도 타점 인정. 볼넷·사구도 밀어내기면 타점(선구안=타자 능력). 출처: 나무위키(타점), BL Brothers 정리.

## 타점이 안 되는 경우
- **병살타 도중 득점** / **실책으로 득점** / 폭투·포수 뒤로 빠진 공(포일)·보크로 득점 / 도루로 홈 훔침. → 타자의 공이 아니므로 타점 없음.

## 예외 (규칙 디테일)
- **무사 또는 1사에서, 3루 주자가 실책이 없었어도 충분히 득점할 수 있었던 상황이면, 도중에 실책이 껴도 타점 인정.** 출처: 나무위키(타점).

## 왜 중요 + 한계
- 해결사·클러치의 상징. **단, 앞 타자들이 출루해 있어야만 올릴 수 있어 타순·팀 의존적** → 순수 개인 실력 지표로는 한계.

## 유래
- **MLB 공식 기록 채택 1920년.** 100년 넘게 타자 생산력 대표 지표.

- **통산 최다: 최형우 1,733타점 — 역대 1위** (이승엽 1,498 경신). 최정 1,619, 김현수 1,518 뒤따름. 출처: 위키백과·나무위키(KBO 타점 기록).

## 삽화 주의

- 만루·홈 쇄도·병살 씬은 상황 묘사로. 숫자 삽입 위험 → "NO numbers/text" 강조.
