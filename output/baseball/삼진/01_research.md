# 야구사전 31편 "삼진(Strikeout, K)" — 리서치 노트 (웹 교차검증)

## 정의
- **삼진 = 타자가 스트라이크 3개로 아웃.** 타자=삼진 당함 / 투수=탈삼진(삼진 빼앗음). 같은 장면, 이름만 다름.

## 종류
- **헛스윙 삼진(swinging K)**: 방망이 휘둘렀는데 헛침.
- **루킹 삼진(called K, 서서 삼진)**: 안 휘두르고 섰다가 스트라이크 콜. 기록지엔 **뒤집힌 K**로 표기(타자에겐 더 굴욕).

## 파울/번트 디테일 (고인물)
- **2스트라이크 후 파울은 삼진 아님** — 스트라이크 상태 유지(무한). **예외: 2스트라이크에서 번트 파울 = 삼진 아웃.**
- 파울팁(포수 미트에 바로 걸림)은 스트라이크 → 3번째면 삼진.

## 낫아웃 연결
- 3번째 스트라이크를 포수가 놓치면 타자가 1루로 뛸 수 있음 = **낫아웃**(6편 참고). 삼진 잡고도 주자 살 수 있음.

## K 표기·문화
- 기록지 **K**. 야구장 관중석 **K 카드** 누적. 한 경기 타자 4삼진 = **골든 솜브레로**(불명예 별명). 5삼진=플래티넘.

## 탈삼진 지표
- 투수 최고 무기(주자 있어도 봉쇄). **K/9**(9이닝당 삼진), **탈삼진왕**(시즌 최다).
- 삼진의 시대: 구속↑ + 풀스윙 → 삼진 급증. 삼진=최악의 아웃(진루 0)이나 병살 위험은 없음(양면).

## 기록 (교차검증)
- **KBO 단일시즌 최다 탈삼진: 아리엘 미란다(두산) 2021 225개** — 역대 1위. 출처: 한국경제·세계일보(2021-10-24).
- **KBO 통산 최다 탈삼진: 송진우 2,048로 오래 1위 → 2024년 양현종(KIA)이 경신, 역대 1위(2,053+).** 출처: 경향신문(2024-08-21), KBO.
- **MLB 통산 탈삼진: 놀런 라이언 5,714** (경신 불가). 단일시즌(모던) 놀런 라이언 1973 383. 출처: 나무위키·위키(놀런 라이언).

## 삽화/영상 주의
- 실존 선수 얼굴 금지 → 유니폼 색·상황. 전광판 숫자·영문 텍스트 금지(단 'K' 카드 컨셉은 상황상 허용 여부 검토 — 안전하게 텍스트 없이 표현 권장).
- 헛스윙·루킹·포수 미트 액션 다수.

## 사실검증 상태
- 정의·헛스윙/루킹·파울(번트 예외)·낫아웃 연결·미란다 2021 225·양현종 통산 경신·놀런 라이언 5714 = 웹 교차확인.
