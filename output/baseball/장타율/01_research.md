# 야구사전 27편 "장타율(SLG)" — 리서치 노트 (웹 교차검증)

## 정의
- **장타율(SLG, Slugging Percentage) = 타자가 친 안타의 "값"(장타력)을 재는 지표.** 한 방의 힘.

## 계산식 (핵심)
- **장타율 = 총 루타수 / 타수 = (단타×1 + 2루타×2 + 3루타×3 + 홈런×4) / 타수**
- 안타로 밟은 베이스 수를 다 더해 타수로 나눔. 출처: Wikipedia(Slugging percentage), 계산기 사이트 다수.

## 타율과의 차이
- 타율은 단타든 홈런이든 똑같이 "안타 1개". **장타율은 홈런을 단타의 4배로 가중** → 거포가 빛남. 안타의 개수가 아니라 무게를 잼.

## 최댓값
- 매 타석 홈런이면 타수마다 4루타 → **이론상 최대 4.000** (타율 최대 1.000과 대조). 그래서 .500만 넘어도 대단.

## OPS 연결
- **OPS = 출루율 + 장타율.** 출루율(얼마나 자주 나가나) + 장타율(얼마나 세게 치나) = 득점 생산력. 장타율은 그중 "파워" 반쪽. (24편 OPS·26편 출루율과 연결)

## 기준
- .400 준수 / .500 중심타자 / **.600+ 괴물.**

## KBO 기록 (교차검증)
- **단일시즌 최고: 에릭 테임즈 2015 .790** (NC). **1982년 백인천 .740을 33년 만에 경신.** 출처: 위키백과(2015 KBO), 나무위키(단일시즌 타자기록·테임즈 2015).
- (통산 장타율 1위는 이번 검색서 특정 수치 미확인 → 대본에선 단일시즌 기록만 사용, 통산 KBO는 언급 안 함. 날조 금지.)

## MLB 기록 (참고)
- **단일시즌: 배리 본즈 2001 .863.** **통산 1위: 베이브 루스 .690** (100년 가까이 유지). 출처: Wikipedia(career SLG leaders).

## 삽화 주의
- 실존 선수 얼굴 금지 → 유니폼 색·상황으로. 전광판 숫자·영문/숫자 라벨 금지 명시.
- 루타 계산(s03)·최댓값(s05)·기준(s08) 씬은 AI가 숫자/영문 넣기 쉬움 → "NO text/numbers" 강조. 베이스 밟는 이미지로 표현.

## 사실검증 상태
- 계산식(루타 가중)·타율 차이·최댓값 4.0·OPS 관계·테임즈 2015 .790·백인천 1982 .740·본즈 2001 .863·루스 통산 .690 = 웹 교차확인.
- KBO 통산 장타율 1위 수치는 미확인이라 대본 미사용.
