(쉼) Claude도 똑같아요. 그때그때 말로 부탁하면 매번 조금씩 다르게 일해요. 오늘은 그림을 이 폴더에 넣었다가, 내일은 저 폴더에 넣기도 하죠. 하지만 레시피처럼 글로 적어 두면, Claude는 매번 그 순서와 기준을 똑같이 따라 해요. 이 레시피 카드를 우리 강의에서는 규칙서라고 부를 거예요.

## [02:00 – 03:30] (챕터 02:00 – 03:30) 규칙서와 프로그램은 어떻게 다를까

- **화면**: VS Code 좌우 분할 — 왼쪽 `정상예시/CLAUDE_완성예시.md` 의 "4. 시험 실행", 오른쪽 `내_작업실/시험실행.py` 의 `[설정]` 블록
- **동작**: 왼쪽 "결과물 저장 위치: 결과/시험실행/" 줄 형광펜 → 오른쪽 `SAVE_DIR = HERE / "결과" / "시험실행"` 줄 형광펜 → 두 줄을 화살표로 연결

> 그럼 규칙서와 프로그램은 뭐가 다를까요? 화면 왼쪽이 규칙서, 오른쪽이 프로그램이에요. (쉼) 규칙서는 사람과 AI가 읽는 문서예요. 무엇을, 어떤 순서로, 어디에 저장할지를 우리말로 적어요. 여기 보시면 "결과물 저장 위치는 결과, 시험실행 폴더"라고 적혀 있죠. (쉼) 오른쪽 프로그램은 컴퓨터가 읽는 파일이에요. 규칙서에 적힌 내용을 실제로 실행해요. 같은 내용이 여기, 세이브 디렉터리라는 줄에 들어 있어요. (쉼) 정리하면, 규칙서는 레시피 카드이고 프로그램은 그 레시피대로 요리하는 손이에요. 그래서 레시피를 바꾸고 싶으면 먼저 규칙서를 고치고, 프로그램은 Claude에게 규칙서에 맞춰 달라고 부탁하면 돼요. 코드를 직접 고칠 필요가 없어요.

≈ 나레이션 64초 + 화면 동작·쉼·대기 26초 = 90초

(쉼) 나머지 줄은 화면 오른쪽 완성 예시를 보면서 똑같이 채우셔도 괜찮아요. 처음에는 따라 쓰고, 익숙해지면 내 방식으로 바꾸면 돼요.
