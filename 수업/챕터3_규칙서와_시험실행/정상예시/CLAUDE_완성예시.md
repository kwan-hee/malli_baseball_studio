# 공통 규칙서

## 1. 이 작업실이 하는 일

- 만드는 것: 5~7세 아이를 위한 4분짜리 동화 영상 (10장면, 성우 나레이션, 바닥 자막)
- 주인공 캐릭터: 말리(연습용) — 캐릭터 시트는 `말리_연습자료/` 에서만 가져온다
  (글: 말리_캐릭터시트.txt / 그림: malli_reference.png — 그림을 만들 때마다 둘 다 첨부)

## 2. 제작 순서와 단계별 입력·출력

| 순서 | 단계 | 입력(무엇을 받아서) | 출력(무엇을 만든다) | 저장 위치 |
|---|---|---|---|---|
| 1 | 동화 고르기 | 저작권 끝난 동화 목록 | 후보 4개 중 1개 | 대화 |
| 2 | 이야기 개요 | 고른 동화 | 주인공·교훈·줄거리 3줄·순화 방법 | 결과/{편}/개요.md |
| 3 | 대본·장면 나누기 | 승인된 개요 | 10장면 대본 + 점수표 + 배정표 | 결과/{편}/대본.md |
| 4 | 그림 | 대본 + 캐릭터 시트 | 장면 그림 10장 | 결과/{편}/그림/ |
| 5 | 목소리 | 대본 전체 | 나레이션 1개(한 번에 녹음) | 결과/{편}/목소리/ |
| 6 | 움직이는 장면 | 배정표에서 고른 그림 2장 | 8초 영상 2개 | 결과/{편}/영상/ |
| 7 | 조립 | 그림·목소리·영상 | 완성 영상 1개 | 결과/{편}/완성.mp4 |

## 3. 중간 확인 지점 (돈이 들기 전, 딱 두 번)

- 확인 ①: 2단계가 끝나면 → 이야기 개요를 보여 주고 내 승인을 기다린다
- 확인 ②: 3단계가 끝나면 → 배정표(어느 장면을 그림/영상으로 만들지)를 보여 주고 내 승인을 기다린다
- 두 번 승인한 뒤에는 끝까지 묻지 않고 진행한다

## 4. 시험 실행 (처음 한 번)

- 프로그램: 시험실행.py
- 만드는 것: 그림 1장, 목소리 1문장
- 목소리 문장: "안녕하세요, 여러분! 저는 말리예요. 오늘 우리 작업실이 잘 되는지 같이 시험해 볼까요?"
- 결과물 저장 위치: 결과/시험실행/ (malli_test.png, malli_test.wav)

## 5. 결과물 저장 위치

- 편마다: 결과/{편 이름}/
- 그림 / 목소리 / 완성 영상: 그림/ / 목소리/ / 완성.mp4

## 6. 꼭 지킬 것

- 우리 아이 실제 사진은 AI에 올리지 않는다 (연습은 예시 사진으로)
- API 키는 .env 파일에만 두고 화면에 보이지 않게 한다
- 원인을 모르는 오류가 나면 코드를 바로 고치지 말고, 오류 문구를 먼저 보여 준다
