# 말리의 동화나라 — 강의 소개 영상 통합 콘티

## 문서 안내 — 전사 편집 정보

- **원본 순서:** `01.png` → `02.png` → `03.png` → `04.png` → `05.png` → `06.png`.
- **전사 범위:** 각 이미지의 단계 제목, 타임라인 표, 제작 메모, 마지막 합계. 화면 너비 때문에 끊긴 문장만 이어 적었으며, 내용을 요약하거나 대사를 새로 작성하지 않았습니다.
- **장면 식별자:** `S01-01`은 STAGE 1의 첫 번째 장면입니다. 시간은 원문의 값을 유지하면서 `MM:SS` 형식으로 통일했습니다.
- **필드 구분:** 각 장면을 `화자`, `대사`, `화면 지시`, `소리`로 구분했습니다. 대사 칸에 있던 제작 메모는 해당 장면의 `원문 제작 메모`로 분리했습니다.
- **대사 해석:** `-`, `(쉼)`, `(쉼 0.5초)`, `(영상 클립: …)`는 원문에 적힌 무대사·정지·클립 구간 표기입니다. 이 표기와 화면 지시, 소리, 제작 메모는 낭독 문장이 아닙니다.
- **공란 해석:** `[원문 공란]`은 원본 셀에 글이 없다는 뜻입니다. 이를 무음이나 이전 설정 유지로 임의 해석하지 않았습니다.
- **화자 이름:** 원문의 자기소개에 따라 `🐶`는 말리, `🎙️`는 릴리로 이름을 병기했습니다. 작은 이모지는 의미가 같은 유니코드 기호로 옮겼으므로 원본과 표시 모양이 다를 수 있습니다.
- **캡처 UI:** `06.png` 왼쪽 위에 겹친 잘린 UI 도움말은 콘티 본문에 포함하지 않았습니다.
- 이 안내와 아래 전체 구성 표는 Claude Code가 문서를 읽기 쉽게 덧붙인 편집 정보입니다. 각 STAGE의 장면 내용과 원문 제작 메모는 이미지 전사입니다.
