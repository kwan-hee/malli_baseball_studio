# 강의 샘플: 「하린이와 초코의 이상한 나라」 설계

작성일: 2026-10-20
상태: 사용자 승인 대기 (이 문서 = 1차 게이트 이야기 개요 겸 설계)

## 1. 의도와 이유

사용자가 "AI로 우리 아이·반려동물 동화 만들기" 강의를 맡았다. 강의 대상은 영상 입문자, 아이에게 동화를 선물하고 싶은 부모, 반려동물을 캐릭터로 남기고 싶은 반려인이다.

이 샘플은 강의 화면에 띄워 **"사진 한 장에서 우리 아이와 우리 강아지가 주인공인 동화가 태어난다"**는 것을 보여 주는 시연물이다. 수강생이 "나도 할 수 있겠다"고 느끼는 것이 성공 기준이다.

강의 목록(수강 후 할 수 있는 것)과 샘플 결과물의 대응:

| 강의 항목 | 샘플 결과물 |
|---|---|
| 아이·반려동물을 닮은 캐릭터 (수채화 2D) | ① 캐릭터 탄생 과정 비교 이미지 |
| 옛이야기 바꾸기로 동화 쓰기 | 이상한 나라의 앨리스 각색 대본 |
| AI 목소리 고르기 | Gemini TTS 나레이션 |
| 영어 버전 | ③ 영어 영상 |
| 3~4분 동화 영상 | ② 한국어 영상 |
| (추가) 잠자리 그림책 | ④ 그림책 전자책 |

## 2. 결과물 4종

1. **캐릭터 탄생 과정**: 원본 사진 → 수채화 캐릭터 시트를 나란히 놓은 비교 이미지 2장 (하린, 초코). 강의 슬라이드에 그대로 쓸 수 있게 16:9 PNG. 가족 사진은 AI로 만든 예시 사진이므로(사용자 확인) 비교 이미지에 'AI 생성 예시 사진'이라고 작게 표기한다. 원본은 `images/portraits/`를 쓴다(`family_test/딸.jpg`는 다른 인물이라 사용 안 함).
2. **한국어 영상**: 3~4분, 1280x720, 기존 동화 파이프라인(gen_images → make_narration → compose)으로 조립.
3. **영어 영상**: 같은 그림·같은 클립에 영어 나레이션과 영어 자막만 바꿔 조립.
4. **그림책 전자책**: 엄마가 아이를 재울 때 태블릿으로 읽어 주는 그림책. 씬 1개 = 펼침면 1쪽. 그림 크게 + 짧은 글. 쪽마다 **음성 듣기 버튼**(그 쪽 나레이션 재생)이 있고, 버튼을 누르지 않으면 조용한 그림책으로 엄마가 직접 읽는다.

## 3. 주인공

- **하린** (사용자가 이름 짓기를 Claude에게 맡김 → 확정): `images/portraits/daughter.png` 기반. 양갈래 머리 + 노란 방울 머리끈 + 분홍 원피스를 고정 식별 요소로 유지.
- **초코** (확정): `family_test/강아지.jpg` 기반 갈색 토이푸들, 빨간 목줄.
- **엄마** (조연, 마지막 장면만): `images/portraits/mom.png` 기반. 머스터드색 카디건.
- **앨리스**: 원작(1865, 퍼블릭 도메인) 기반. **디즈니 디자인(하늘색 원피스+흰 앞치마+검은 머리띠 조합) 회피** → 연두색 원피스, 금발, 노란 리본 등으로 독자 디자인.
- 이야기 속 말리(채널 캐릭터)는 등장하지 않는다. (Claude 판단: 강의의 메시지가 "우리 아이가 주인공"이므로)

## 4. 이야기 개요 (1차 게이트)

- 교훈 한 줄: **"함께라면 낯선 곳에서도 길을 찾을 수 있어요."**
- 톤: 잠자리 동화. 무섭지 않게, 마지막은 졸리고 포근하게.
- 순화: 하트 여왕의 "목을 베어라" 제거 → 장미에 물감을 쏟아 화가 난 투덜이 여왕. 추격은 카드 병정들이 허둥지둥 쫓다가 바람에 와르르 흩어지는 코믹 소동.

| 씬 | 장면 | 나레이션 핵심 |
|---|---|---|
| s01 | 밤, 하린 침대. 초코와 앨리스 그림책을 보다가 하품. 그림책 속 굴이 반짝이고 초코가 뛰어든다 | 잠들기 전 이야기 시작 |
| s02 | 하린이 초코를 따라 굴 아래로 둥실둥실. 찻잔·시계·책이 함께 떠다닌다 | "초코야, 기다려!" |
| s03 | 작은 문이 있는 방. "나를 마셔요" 병으로 작아지고, 거기서 앨리스를 만난다 | "너희도 길을 잃었구나?" |
| s04 | 체셔 고양이가 웃음만 남기고 사라지며 길을 알려 준다 | "집으로 가는 문은 여왕님 정원 너머에 있지" |
| s05 | 모자 장수의 "생일 아닌 날" 차 모임. 시계 모양 열쇠를 선물받는다 | 즐거운 후렴 |
| s06 | 하트 여왕 정원. 초코가 장미 칠하던 물감 통을 엎는다. 여왕이 발을 구른다 | "누가 내 장미를!" |
| s07 | 탈출. 카드 병정들이 허둥지둥 쫓아오다 바람에 와르르 흩어진다. 셋이 손잡고 달린다 | 절정 |
| s08 | 숲 끝 작은 문. 열쇠로 열고 앨리스와 작별. "또 놀러 와" 약속 | 우정 |
| s09 | 빛을 지나 침대에서 눈을 뜬다. 초코가 옆에 있고, 베개 옆에 작은 하트 카드 한 장 | 꿈이었을까? |
| s10 | 엄마가 이불을 덮어 준다. 하린 "내일 밤에도 앨리스 꿈 꿀래" 하며 잠든다. 교훈 한 줄 | 포근한 마무리 |

후렴(아이가 따라 말할 수 있는 반복구) 후보: "초코야, 같이 가자!" — s02, s05, s07에서 반복.

## 5. 제작 방식 (리포 기존 규칙 그대로)

- 폴더: `output/storybook/하린이와_초코의_이상한_나라/`. 템플릿 = 41편 `말리와_욕심쟁이_개` 스크립트 3종 복사, SCENES·SCENE_STYLES·STYLE·파일명·VIDEO_SCENES만 수정 (CLAUDE.md 최소 변경 원칙).
- 그림: 10컷, 수채화 2D 그림책풍. 캐릭터 시트(하린·초코·앨리스)를 먼저 만들어 2차 게이트에서 함께 확인받고, 매 씬 생성에 multimodal 참조로 첨부. 이미지 모델 = 템플릿과 동일(gemini-3-pro-image-preview).
- 영상 클립: 13_SCENE_SCORING 규칙(motion 7+ AND importance 85+)으로 2개 내외. 예상 후보 s02(낙하), s07(탈출). 플랫폼 = 동화 기본(Google Flow / Veo 3.1 Fast). **2차 게이트에서 배정표 승인 후에만 생성.**
- 한국어 TTS: gemini-3.8-flash-tts, Kore, 전체 대본 단일 호출 + 씬별 style. 행동 지문 금지, 자막 MarginV=10.
- 영어 TTS: 같은 모델·같은 방식, 영어 대본 단일 호출. 영어 자막 폰트는 Claude 선택.
- BGM: `assets/bgm/storybook/` b1→b2 한 바퀴 + 페이드아웃 + 무음 패딩.

## 6. 그림책 전자책

- 형식: **EPUB 3 고정 레이아웃(가로 16:9 페이지)**. 쪽마다 그림 + 그 씬의 나레이션 전문 + 음성 버튼. (Claude 판단: 엄마가 읽는 글과 버튼 소리가 똑같아야 어긋나지 않음. 동화 문장이 15자 내외라 씬당 4~6문장도 한 쪽에 들어감)
- **한국어/영어 전환 버튼** 포함. 영어 음성은 영어 영상 제작 때 씬별로 나뉘는 wav를 재사용하므로 추가 TTS 없음. (Claude 판단: 강의 항목 '영어 버전'과 맞춤)
- 음성은 한·영 영상의 씬별 wav를 mp3로 변환해 재사용한다(추가 TTS 비용 없음).
- 시연 기기 = **아이패드**(사용자 확인). 주 시연본은 Apple Books로 여는 EPUB.
- 예비 시연본: 그림·오디오를 모두 내장한 **단일 HTML 파일**(iPad Safari는 로컬 폴더의 상대경로 오디오가 막히기 쉬움). 파일 하나만 아이패드로 옮기면 열린다.
- 잠자리용 화면: 어두운 배경, 페이지 넘김 효과 최소, 자동 재생 없음.
- 표지 1쪽 + 본문 10쪽 + 마지막 쪽("오늘 밤 꿈에서 또 만나요").
- 검증: epubcheck 통과 + 아이패드 화면 크기 브라우저에서 단일 HTML 넘김·음성 버튼·언어 전환 동작 확인. Apple Books 실기 확인은 사용자 몫(Claude가 직접 못 함).

## 7. 목표가 아닌 것

- 유튜브 채널 업로드용 편이 아니다 → 말리 인사, 구독·좋아요 CTA, SEO·제목 엔진, 썸네일, 쇼츠 생략. (Claude 판단)
- 서점 판매용 전자책 등록(ISBN, 교보·리디 심사)은 이번 범위가 아니다.
- 수강생용 실습 도구·교재는 다음 프로젝트로 분리.

## 8. 실패로 보는 것

- 캐릭터가 사진 속 아이·강아지와 닮지 않음 (강의 메시지 붕괴)
- 장면마다 하린·초코 외형이 달라짐
- 앨리스가 디즈니 앨리스처럼 보임
- 잠자리 동화인데 무섭거나 시끄러움

## 9. 진행 순서와 승인 지점

1. (지금) 이 문서 승인 = 1차 게이트
2. 캐릭터 시트 3장(하린·초코·앨리스) 생성 — 2차 게이트 전에 미리 (사용자 선택)
3. 대본(한·영) + 씬 점수표 + 배정표 + 캐릭터 시트 결과 → **2차 게이트**
4. 승인 후 자동 진행: 씬 이미지 → 클립 → TTS(한·영) → 조립(한·영) → 전자책 → 프레임 검증
5. 산출 위치: `output/storybook/하린이와_초코의_이상한_나라/`, 최종본은 Obsidian `50_Outputs/말리동화/강의샘플/`
